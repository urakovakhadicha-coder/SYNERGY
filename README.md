# Synergy — перенос на Railway

Готовая версия сайта от 12 октября 2026 года. Внутри: 3 языка, кейсы с фильтрами, страницы услуг, 25 логотипов и форма заявки. Контакты: @BekhruzMusaev, +998 99 033 20 11.

## Размещение через GitHub

1. Распакуйте архив. Откройте папку `synergy-railway`.
2. Создайте репозиторий в GitHub и загрузите **содержимое** этой папки. `Dockerfile`, `package.json` и `server.mjs` должны находиться в корне репозитория, а не внутри дополнительной папки. Сам ZIP загружать в репозиторий не нужно.
3. В Railway создайте проект → **Deploy from GitHub repo** → выберите репозиторий. Для уже созданного сервиса подключите репозиторий в настройках источника.
4. Railway обнаружит `Dockerfile` и выполнит сборку. Отдельные Build Command и Start Command оставьте пустыми. Если Start Command уже задан вручную, удалите его или укажите `npm start`.
5. После успешного запуска откройте **Settings → Networking → Generate Domain**. Если Railway спросит порт назначения, используйте значение `PORT` сервиса; при отсутствии заданного `PORT` приложение слушает 3000.
6. В **Variables** задайте `SITE_URL` равным полученному полному адресу, например `https://ваш-сервис.up.railway.app`, и примените изменения / выполните redeploy. Это обновит canonical-ссылки, языковые альтернативы и sitemap под ваш домен.
7. Откройте сайт и проверьте языки, страницу контактов и подготовку заявки. Telegram откроется с текстом: сообщение отправляет сам посетитель.

Можно использовать собственный домен: подключите его в Networking, внесите DNS-записи, которые покажет Railway, затем обновите `SITE_URL` и примените изменения.

## Настройки

- Запуск: `npm start`.
- Прослушивание: `0.0.0.0`, порт берётся из `PORT` (по умолчанию 3000).
- Healthcheck, если хотите включить: `/`.
- `SITE_URL`: полный основной адрес сайта без пути, с `https://`.
- Если `SITE_URL` не задан, используется `RAILWAY_PUBLIC_DOMAIN`, а при его отсутствии — локальный адрес.
- База данных, токен Telegram-бота, ключи API и отдельный диск не нужны.
- В этой версии заявки не сохраняются на сервере и не отправляются автоматически. Форма составляет текст для чата @BekhruzMusaev.

## Запуск на компьютере

Нужен Node.js 22 или новее. В папке проекта выполните:

```sh
npm start
```

Откройте http://localhost:3000. Установка сторонних npm-пакетов не требуется.

## Где редактировать

- `src/content.mjs` — тексты на русском, узбекском и английском.
- `src/render.mjs` — структура страниц и контактные ссылки.
- `src/logic.mjs` — Telegram-получатель и логика формы.
- `src/browser.mjs` — меню, фильтры и взаимодействия.
- `src/logos.json` — список логотипов.
- `public/styles.css` — оформление.
- `public/assets/` — изображения и логотипы.

`npm start` пересобирает HTML из исходников перед запуском сервера. Для ручной сборки: `npm run build`. Не редактируйте сгенерированные HTML вручную — при старте они будут созданы заново.

Архив автономен: он не содержит учётных данных, Git-истории или конфигурации публикации ChatGPT Sites. Размещение в Railway выполняется отдельно. Исходный сайт в Sites не отключается.
